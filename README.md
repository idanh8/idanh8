# Idan Horowitz

Data scientist and ML researcher completing my M.Sc. Data Science at the Technion.

I enjoy understanding why models behave the way they do, designing experiments to test an idea, and building useful applications around the results. My work spans deep learning calibration, LLM evaluation, and applied AI systems.

Previously, at Caps For Sale, I built data and geospatial feature-engineering workflows for a commercial real estate analytics product.
